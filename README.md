# AgriConnect

AgriConnect is a data analytics-based smart floriculture farmer–retailer management and matching portal.

## Frontend Technologies
- HTML5
- CSS3
- JavaScript
- Bootstrap 5

## User Roles
- Farmer: List flowers and request seeds.
- Buyer: Submit flower requirements and discover matching flowers.
- Seed Supplier: List seed products and manage stock.
- Florist: Discover flowers through the marketplace.

## Frontend Features
- Flower marketplace with search, filters and sorting
- Farmer flower listings
- Buyer flower requirements
- Farmer seed requests
- Seed supplier product management
- Login and registration interfaces
- Responsive navigation

## How to Run
1. Clone or download this repository.
2. Open the frontend folder.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Backend Integration Status
The frontend currently uses demo interactions. Permanent database storage, authentication, and data sharing between user dashboards must be connected to the backend.

## Team Development
The frontend and backend are being developed separately and will be integrated after the API endpoints and database structure are agreed upon.
